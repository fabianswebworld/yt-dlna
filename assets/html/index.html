Online Playlists

Online Playlists are managed by the streaming services they are hosted on. Add an Online Playlist using its URL, and that playlist will be synced to yt-dlna's library so it can be browsed with your DLNA client.
More info...

An Online Playlist can be e.g. a YouTube playlist, TV show, or other collection from a broadcaster's streaming portal. For YouTube playlists, instead of the full URL, you can also use just the list= token from the URL.

Note that only the metadata of the entries are kept in the library - no videos are ever downloaded; instead, they are streamed to you DLNA client on-the-fly whenever you select them. To achieve this, yt-dlna's proxy server will redirect your DLNA client directly to the resolved CDN URL (in redirect mode), or tunnel the streams to the DLNA client (in proxy mode, which can be useful for older DLNA clients that don't follow HTTP redirects). See the Settings tab for the mode settings.

Custom Playlists

Custom Playlists are playlists managed and curated locally. When you add a Custom Playlist, it will be saved in a local file and can be edited using the Custom Playlist Editor. Use this feature to manage e.g. Bookmarks (Streaming URLs) of your favorite Radio Stations.
More info...Custom Playlists can be organized hierarchically and can contain one or more subfolders, allowing for a custom navigation structure. URLs in Custom Playlists are always treated as static URLs, so no CDN resolving is ever done. Instead, yt-dlna's proxy server will redirect your DLNA client directly to the source URL (in bounce mode), transparently tunnel the streams to the DLNA client (in reflect mode), or simply hit the URL backend-side and stream a dummy audio file to your DLNA client (in hit mode). Using hit mode in Custom Playlists, you can even perform actions in your Home Automation system via your DLNA client.
